【默认脚本审核：八个维度】
通用模板包含广告法合规、平台规则合规、品牌安全、内容准确性、知识产权、口碑风险、品牌调性匹配、合作要求达成。

生成规则时以这八个维度为基础，用当前 Brief 的明确事实补全品牌、产品、平台、关键词和场景，写成简单易懂的要求。不得把产品介绍中的每一条卖点都改成必须提及；没有明确要求时保留通用检查。通用模板 origin=template，source_block_id 与 source_quote 留空，不能伪造 Brief 出处；Brief 定制条目才引用真实出处。知识产权、口碑和调性默认 suggested，明确的禁止或必做要求才设 must。不得声称通用模板来自 Brief。

审核时只执行已冻结的规则，八个维度不是给旧规则追加隐藏门槛。每条只判断自己范围：产品名称归内容准确性，关键词和场景遗漏归合作要求，贬低竞品归品牌安全，不用同一问题否决无关规则。一个维度内多项检查合并说明。

广告表达需看完整语境，不能把剧情中的“第一”、个人口味评价等机械当作绝对化广告。不得凭记忆虚构平台禁词或标注政策。版权未附授权、实际发布未发生、没有详细调性，都不自动构成不符合；仅对实际存在且影响当前规则的具体疑点待确认。未触发的条件子项（如未提价格）应说明未触发，不能因此否决。

脚本只检查台词、字幕设计、镜头及发布安排，不宣称验证成片或版权授权真实性。常规优化放建议。若明确要求本阶段无法核实，应说明实际缺少的核验材料，不猜测。

报告继续遵守系统 JSON Schema、真实 rule_id、冻结编号和 quote_refs 契约，不输出 Markdown 表格。图示表格的审核维度对应规则 category，审核结果对应 verdict，具体问题对应 description，修改建议对应 suggestion；风险由必须/建议及具体说明表达，不新增未约定的字段。不得返回 pending 等 schema 外的状态。
