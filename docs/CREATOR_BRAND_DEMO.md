# 品牌端与达人端演示

本次没有增加登录。顶栏「切换到达人端 / 切换到品牌端」用于演示两种视角，刷新保留当前视角；角色切换不是账户或权限认证系统。

## 达人端

- 「我的合作」按演示达人选择合作记录，显示品牌、项目及对应Brief。
- 进入任务后只读查看对应审核参考文件；上传TXT/DOCX/XLSX脚本或粘贴正文。
- 提交即调用品牌设置的模型，使用所属项目统一的脚本规则，不允许客户端传入另一份Brief覆盖审核依据。
- XLSX内嵌图片随脚本文字一起送审，无需另传。品牌规则或Brief更新使旧结果失效时，顶部「按当前规则重新验收」复用现有脚本版本调用当前模型，可能计费，不重复上传或创建脚本版本。页面区分“原文件已提取图片”和“当前规则下有效审核图片”，无运行任务时不提示用户等待后台处理；旧审核不能恢复新规则下的通过资格。
- 反馈显示必须项检查、原文与修改建议。未通过或待确认时要求修改，不进入品牌待审。
- 脚本提交页顶部仅保留单行工具栏，上传通过抽屉打开，历史通过弹窗查看。左侧当前版本解析预览与右侧AI评论占据剩余视口，两栏独立滚动，桌面整页无需滚动。总体意见、必须项与图片说明收入「审核详情」，解析与布局限制收入「解析说明」，默认直接展示表格和评论。Excel 默认显示「Excel原布局」，保留工作表、列宽、行高、合并单元格、常用字体/颜色/边框与图片锚点，可缩放及切换工作表；文字页仍显示实际解析位置并支持搜索，Word/TXT使用解析文字预览。反馈引文按真实文本位置高亮，可点击原文或评论双向定位；选中评论显示连线，滚动/缩放后更新，不可见时隐藏连线。缺失项不伪造单元格位置。预览不额外调用AI，不修改原文件；字体、自动行高、复杂图形与打印效果不保证完全一致。详见 SCRIPT_EXCEL_COMMENTS.md。
- 必须项通过后自动进入品牌待审；品牌通过/退回意见可在达人端查看。

## 品牌端

- 维护品牌产品项目、项目下多个达人、对应Brief来源及项目统一的脚本与视频规则。添加达人无需重复配置规则，规则版本更新同步影响项目全部达人，详见 PROJECT_STANDARDS.md。
- 脚本复核页只读查看达人提交内容、AI必须项验收与反馈，不再放达人上传表单。
- 「待品牌审核」仅列出当前规则/脚本版本的必须项已通过、尚无品牌决定的脚本。视频复核继续保留原有入口。
- 品牌确认通过或退回；通过脚本后，才能继续审核对应视频。

## 必须项验收

规则按顺序固定ruleNumber；AI逐条返回findings，反馈标明违反第几条。Excel文字与图片一起送审，每张图片必须有image_checks；服务端校验规则、编号与图片引用。历史段落模式仍要求mandatory_checks，不会把旧段落报告自动视为完整通过。

服务端重新计算验收资格：

1. 当前AI报告成功且对应当前脚本、当前规则上下文；
2. 有已确认必须项，并有完整的验收结果；
3. 必须项全部为compliant；non_compliant、needs_confirmation或缺失清单均不放行。

旧的结构化标准以每条必须规则的审核结论计算资格；旧段落报告若没有必须项清单，不自动当作通过。建议项不阻塞必须项验收。AI识别自然语言规则仍需品牌核对，AI验收通过不等于品牌最终通过。

品牌决定接口会拒绝未通过验收的脚本（MANDATORY_CHECKS_NOT_PASSED），不是仅靠前端隐藏按钮。新脚本、规则修改仍使旧资格失效。重复网络请求继续使用既有幂等逻辑，不自动重复付费调用。

## 验证

后端集成测试覆盖：未通过、待确认、缺失验收清单均不送审；必须项通过后入队；建议项不阻塞；品牌决定接口强制拦截；新版本失效。

浏览器测试覆盖：角色切换、对应Brief、上传脚本、修改再提交、未通过时品牌列表为空、通过后进入品牌复核、品牌意见回传、刷新保持视角。测试模型为模拟响应，不调用真实收费服务。
