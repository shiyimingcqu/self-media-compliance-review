# 简化脚本审核

当前产品定位：品牌在平台外把Brief直接交给达人。平台只管理审核参考资料、接收脚本和视频并提供反馈，不下发Brief、脚本或任务，不包含发布。

## 品牌操作

1. 在项目中新建审核记录，填写达人名称和平台。
2. 使用默认逐条规则；每条填写要求、判定说明，选择「必须满足 / 建议优化」。支持添加、删除、上移，保存时按顺序固定编号。
3. 上传PDF/TXT Brief，点击「上传Brief并生成规则」。系统通过专用AI提示词生成独立候选规则，自动回填，品牌编辑确认后保存。该上传仅用于审核参考，不下发达人。
4. 达人切换至达人端提交对应脚本：支持粘贴文本和TXT/XLSX/DOCX。点击「提交脚本并进行AI验收」即保存版本并调用模型。
5. 反馈显示「违反第N条」、原文、Excel图片及修改建议。必须项全部通过才能进入品牌复核；品牌通过后继续审查视频。

视频规则独立保存。历史段落规则仍可读取，编辑保存后进入逐条模式；不会擅自按标点拆分历史规则。规则或脚本更新会使之前的资格失效。

## 提示词与模型输入

- script-review.md：多模态脚本审核系统提示词。输入编号规则、全文、单元格文字、图片与来源位置；逐条返回结论，并逐张返回image_checks。
- brief-script-standards.md：Brief生成逐条规则提示词，输出rules与warnings。历史paragraph接口保留兼容。
- 每次调用依旧冻结当时提示词版本、规则文字、脚本版本、模型配置与来源。

## 自动审核接口

POST /api/v1/tasks/{taskId}/scripts/submit-and-review，携带输入内容、configRevision、allowRealCall和Idempotency-Key。先保存脚本，再执行一次多模态兼容接口请求；同一请求重试读取既有审核记录，不重复调用，即使后续模型配置或当前脚本已变化。

解析失败、缺Key或规则变更等情况会保留已提交脚本并明确显示未审核原因，不冒充审核成功。脚本按钮明确说明真实模型费用；上传Brief和自动审查都需要用户主动点击，没有后台自动发起的付费调用。

## Excel 图片审核

支持XLSX内嵌DrawingML图片、WPS cellimages/DISPIMG图片，关联到工作表与锚点单元格。图片原像素转为PNG，与文字一起以image_url传给设置中的模型；不会仅对图片做文字提取。仅有图片的工作簿也能提交。

规则编号由服务器确定；模型返回错号、漏规则、引用不存在的图片、遗漏image_checks时不产生通过资格。图片引用使用image_ids；图片上的文字未出现在提取文本里时，quote留空，在description记录视觉证据，避免伪造文字引用。

限制：最多24张静态图片，单张不超过2000万像素，编码后总量不超过20MiB。不支持读取外链、动画及损坏图片；未覆盖内容会明确显示并阻止品牌复核，不会静默截断后判通过。DOCX图片尚未接入，存在图片时也不会按完整审核放行。

审核快照只存图片位置、尺寸与摘要，不存base64。图片预览通过受控审核记录接口读取并校验源文件SHA256，不能用任意文件路径查看图片。
