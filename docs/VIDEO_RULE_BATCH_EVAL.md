# 实验报告：单次请求规则数量（K）对 VLM 视频审核的影响

日期：2026-10-26 ｜ 模型：qwen3.8-omni-flash（真实调用 10 次）｜ 链路：生产 `EvidenceSession + run_agent + component_runtime`，prompt 版本冻结

## 素材与真值（用户自备，人工抽帧核对）

| 视频 | 产品杯体 | 杯身商标 | "提神醒脑"字幕 | 口播"麦咖啡冰奶铁" |
|---|---|---|---|---|
| v1 有cp1 (20.8s) | 全程 ✓ | 可见 ✓ | ~15s | ~0-3s ✓ |
| v2 无lg1 (20.8s) | 全程 ✓ | ~12s 起灰色块遮挡（时段性） | ~9s | ✓ |
| v3 无cp1 (30.8s) | 无 ✗ | — | ~3s | 无 ✗ |

规则 6 条：r1 产品露出(容忍遮挡)、r2 商标清晰(不得遮挡)、r3 禁用词提神醒脑、r4 必须口播、r5 露出时长≥5s、r6 指定动作。臂：K6=6条全发(生产现状)、K3a=视觉3条、K3b=音频动作3条、K1=单条(r2 最难/r3 安全关键)。

## 结果

### 端到端成功率（组件结果完整落盘且报告合规）

| 臂 | 成功/尝试 | 明细 |
|---|---|---|
| K=1 | **5/6** | v3/r3 失败（3 轮全花在取证，未调 check） |
| K=3 | **0/3** | v2/r1 组件判对了但报告 JSON 非法整单作废；v1 两臂只截图没调 check |
| K=6 | **0/1** | 2 轮截图后作废 |

### 判定质量（组件层证据，不受报告层作废影响）

- **零幻觉**：所有 run 中没有任何一次把不存在的词/产品报成存在。v2/r3 精确报出 `[visible_text] 9500-12900ms matched=True`（真值 ~9s，起点误差 0.5s），同时如实报告 audio/subtitle 通道未命中。
- **零误判通过**：v1/r2、v2/r2 对"商标是否被遮挡"都给了 `needs_confirmation`（保守交人工，其中 v2 是真违规——保守但没放行）；v3/r2 正确 `non_compliant`。
- **取证行为**：9/9 run 全部主动截图取证，时间戳基本落在关键事件上（v1 截在 12.8s 商标展示、v2 截在字幕帧）。但取证与 check 调用在抢同一份轮次预算（max_rounds=3, max_tool_calls=12）。

### 失败模式分解（关键发现）

K 越大失败越多的原因**不是判断变差**，而是流程挤占：

1. **取证挤占检查**：模型倾向先 `capture_evidence_image`/`cut_evidence_clip` 再看情况，规则少时来得及补调 check，规则多时轮次耗尽（v3/r3 用掉 get_rule_source+截图+切片段，3 条 check 一次没调）。
2. **最终 JSON 遵循率随输出体量崩塌**：单规则的最终报告基本合规；3 条以上时报告 JSON 频繁非法（与上一实验合成探针的 4/6 一致）。
3. 组件调用完整性同样随 K 下降（漏调 check 的比例 K=1 < K=3 < K=6）。

## 结论与建议

1. **当前管线参数下 K=1~2 可靠、K=3 边缘、K=6（生产现状）实际吞吐≈0**。但这是"预算/流程设计不匹配 K"而不是"模型能力不匹配 K"——判定质量在 K=6 的有限证据里依然没有变差。
2. 直接可做的修复（不增加调用次数，收益最大）：
   - **强制先 check 后取证**：工具描述或 system prompt 加硬约束"每条规则必须先调用对应 check_* 工具，取证仅用于补充证据"；或在检测到未调齐 check 前拒绝取证工具（工具层闸门，与你们"程序管纪律"的哲学一致）。
   - **轮次预算与 K 挂钩**：max_rounds=3 对 6 条规则根本不够（每轮 1 条消息往返 30-60s）。要么按 K 放大预算，要么反过来——**K=2~3 一组 + 组内串行 check 优先**，是当前模型能力下的甜点。
   - **报告层复用 revalidate 思路**：最终 JSON 非法时组件结果其实已落盘，可本地重建报告（r2/r5 这类单组件规则的报告条目可由 componentResults 直接生成，不需要模型再吐一遍）。
3. 推荐生产形态：**K=2~3 分组（按组件类型聚组：视觉组/音频组），组内 check 优先闸门 + 报告可重建**。相比 K=6 单次，调用数 ×2~3 但吞吐从 ≈0 变为可用；相比 K=1，成本减半且未观察到质量损失。
4. 时间戳精度（字幕 9.5s vs 真值 9s）与语义判断（时段遮挡交人工）都达到"可作证据"水平，维持上一实验结论：VLM 判断够用，ASR 做校准锚点。

## 局限

每臂 n=1（K=1 臂 n=3），自一致性未充分测量；遮挡判定 v2 保守交人工无法区分"看见了不确定"与"没看见"（需人工看模型截图确认）；30 秒短片、单场景，多场景快切视频未测。
