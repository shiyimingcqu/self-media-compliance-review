# AI 调用计时

各 AI 场景右侧使用统一计时组件：运行中显示“已用时 N 秒”，成功后停在“N 秒完成”，失败显示“N 秒 · 未完成”，服务中断显示“N 秒 · 已中断”。

覆盖 Brief 项目信息识别、图文解析和事实卡、脚本/视频规则生成、脚本/图文/视频验收、模型连接测试。普通文件上传、本地压缩、保存配置、人工核对和本地恢复不作为新的 AI 调用计时。

前台同步请求发出时立即开始，收到结果后优先使用服务端记录；后台任务用持久化 createdAt / updatedAt，刷新不会从零开始。推荐、脚本、图文、视频和 Brief 模型调用在完成时保存 result.durationMs，后续本地恢复或人工派生报告保留原始耗时。切换任务或历史记录显示对应记录，未记录结束时间的旧数据不伪造完成耗时。

计时表示处理用时，包含排队、准备、传输及校验，不是服务商的纯模型推理耗时。Brief 自动流程展示整条处理流程的总用时，阶段切换不会清零。

验证使用固定响应，无真实计费调用；覆盖运行阶段、结束后冻结、失败/中断、历史时间与本地恢复保留时长，以及网页运行/完成展示。
