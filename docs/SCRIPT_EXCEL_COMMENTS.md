# Excel 脚本原布局与评论

达人提交的 XLSX 可按原工作表结构预览：合并区域、列宽行高、字体、填色、边框、文字对齐、换行以及可解码的内嵌图片。支持切换工作表、适应宽度及50%～150%缩放，也可切回解析文字与图片页对照。当前预览属于不可变脚本版本，不套用另一版本的图片或审核意见。

右侧按规则显示评论卡片，包含编号、结论、真实引文、位置和修改建议。逐字引文映射至当前脚本的来源块，多单元格引文拆开标记；图片反馈按有效图片ID关联真实锚点。一处原文可对应多个评论。选中原文标记或评论会双向定位并绘制一条连线；滚动、缩放与窗口变化后重新测量坐标，目标不可见则隐藏，不把线固定到错误行。窄屏改为上下排列，通过编号定位，不显示跨栏连线。

没有直接引用的缺失项或整体意见标为“无对应原文位置”，引用无法映射时提示核对原文件；不凭规则内容猜位置。只有通过报告校验且版本匹配的反馈参与标记，未通过校验的模型原始返回仍仅用于诊断。

读取为本地操作，不调用模型，不执行公式、宏、外部链接或图片URL。公式只显示保存的缓存值；无缓存明确标注未知。浏览字体、自动行高、复杂图形、条件格式和打印分页效果不保证与桌面Excel一致，原文件链接保留。隐藏的工作表/行列以淡色展示并提示，避免审核漏看。最多前10张表、单表500行/32列、总计20000个网格位置，超限明确提示，不改变AI实际审核输入与覆盖判断。

接口：

- `GET /api/v1/tasks/{taskId}/scripts/{versionId}/layout`：校验任务归属、文件哈希后返回只读布局模型。
- `GET /api/v1/tasks/{taskId}/scripts/{versionId}/layout/images/{imageId}`：检查同一版本、受控图片ID及文件完整性，返回本地解码的PNG。

布局请求按脚本版本缓存；不保存额外用户文件。读取失败时保留文字预览和原文件入口，不让布局故障影响已有AI结果。
