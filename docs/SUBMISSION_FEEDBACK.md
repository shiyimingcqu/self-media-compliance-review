# 品牌查看未通过提交记录

品牌在项目详情的“项目统一审核规则”、项目规则编辑页、品牌脚本复核和视频验收页均可点击“查看未通过记录”。项目入口汇总本项目达人，单达人验收入口默认只查该合作任务；支持达人名称搜索、脚本/视频、失败原因筛选和分页。

记录按以下原因区分：

| 原因 | 含义 |
| --- | --- |
| 内容需修改 | 已返回报告中的必须项建议不符合，不等于品牌已裁决 |
| 待人工确认 | 必须项待确认/未判定、覆盖待补或格式修复需人工核对 |
| 调用异常 | 连接、格式、证据引用等原因使审核未完成，不能据此认定内容不合格 |
| 品牌退回 | 该次审核记录最新关联的品牌决定为退回 |

每次审核记录独立展示，不因后续重提通过而隐藏早期未通过记录；同一记录优先归类为调用异常，其次品牌退回、内容需修改、待确认，避免重复计数。建议项本身不作为失败触发条件。历史规则来自调用冻结快照，与当前已保存规则按 ID、要求、判据及重要性对照；规则调整后不会用新规则文字覆盖旧反馈。

详情支持当时的脚本文字、原文件或视频、已有取证附件、逐条意见及完整历史规则。调用未完成时附件和未校验反馈明确仅供诊断，不授予通过资格。不返回供应商地址、原始模型大段返回或密钥配置。

记录只读，不自动删改规则、重调模型或改历史审核状态。品牌对照后仍需在规则编辑页明确保存调整，依现有机制使旧结果失效。打开记录和关闭详情不会覆盖当前规则草稿。

接口：

- `GET /api/v1/projects/{projectId}/submission-feedback`：可选 scope、taskId、creatorName、outcome、offset、limit。
- `GET /api/v1/projects/{projectId}/submission-feedback/{script|video}/{id}`：当时规则、材料和反馈详情。

接口限本地使用，按项目和合作归属校验，归档历史仍可只读查阅；跨项目记录返回404。汇总范围为已落库的脚本审核和视频调用记录，不包括在上传/登记前已失败且未留下审核记录的请求。

验证覆盖：历史失败与后续成功并存、旧规则快照、建议项不误记失败、调用异常单独统计、品牌退回、分页筛选、跨项目隔离、归档只读及浏览器查看后草稿保留。测试使用固定记录，不调用真实模型。
