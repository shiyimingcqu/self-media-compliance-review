# 实验报告：VLM 音频审核能力评测（线路 A 阶段二/三前置决策）

日期：2026-10-26 ｜ 模型：qwen3.8-omni-flash（用户自有 Key，真实调用 8 次视频 + 1 次文本连通性）
对照通道：本地 faster-whisper base（vad_filter+beam5, language=zh）｜ 金标准：合成探针构造时已知毫秒偏移

## 方法

6 条合成探针（edge-tts 中文语音按已知时间轴合成进 34s 视频，BGM 变体），词表：必须项 {麦咖啡新品, 第二件半价, 限时优惠活动}，禁用词 {全网最低价, 买到就是赚到}。复用生产链路 `EvidenceSession + run_agent + component_runtime`（冻结 componentPlan、真实 video-review prompt），读取组件级观察与判定打分。P4 含语义等价句（"只需要一半的价格" ↔ "第二件半价"），P5 不含任何目标词（测幻觉），P6 含禁用词。

## 结果

### 判定准确性（VLM 组件 verdict vs 真值）

| 探针 | 条件 | required_speech | forbidden_expression | 结论 |
|---|---|---|---|---|
| P1 | 干净 | 存在项全检出 ✓（缺失项判定因未调用该组件被截断） | — | 部分 |
| P2 | 轻BGM | r1 ✓ 逐词定位；r2 ✓ | r3 未调用 ✗ | 调用完整性缺口 |
| P3 | 重BGM(0.3) | r1 ✓ 仍清晰检出 | r2/r3 未调用 ✗ | 同上 |
| P4 | 语义等价句 | r1 ✓ **语义等价判命中、缺席项正确拒绝**；r2 ✓ | — | 语义能力独有 |
| P5 | 目标全缺席 | r1 r2 均正确 non_compliant ✓ | 正确 compliant ✓ **零幻觉** | 全对 |
| P6 | 含禁用词 | r1 ✓；r2 正确判缺失 ✓ | 正确 non_compliant ✓ 精确检出 | 全对 |

- 口播召回：所有真值存在的口播 6/6 检出，0 漏报。
- 缺失判定：P4/P5/P6 的 6 个"不存在"断言全部正确拒绝，0 幻觉。
- 语义等价：P4 证明 VLM 能把"第二件只需要一半的价格哦"判为"第二件半价"命中，同时不因该句而虚报"麦咖啡新品"——纯文本匹配做不到的能力。

### 时间戳质量

VLM：普遍存在 **+1.0～1.5s 系统性正偏移**（真值 3.0s → 报 4.0-7.0s；14.0s → 报 15.0-18.0s），但跨度与相对次序稳定。
ASR：±0.2s 级精度，明显更准；但文本存在同音错字（第二件半**架**、**现**实优惠、芯瓶/麥咖啡繁体化），纯字面匹配会因错字漏判。

### 端到端管线成功率（重要发现）

**6 次运行 0 次完整成功**，且失败全部是格式遵循问题而非判断能力问题：

- 4× `FINAL_REPORT_INVALID_JSON`（最终轮未按 schema 输出纯 JSON，组件级观察其实已正确落盘）；
- 4× 组件漏调用（如 P2 未调用 r3 禁用词检查——"不存在就不检查"倾向，生产中由 `COMPONENT_CHECK_INCOMPLETE` 正确拦截，不会假通过，但整单作废）。

### coverage_complete 自述诚实度

VLM 声称完整覆盖的运行中（P1/P4/P5/P6），未发现虚报（无"声称听全了却漏掉存在项"）。样本太小，不足以定论，但至少未违反。

## 结论（对照预设判定标准）

| 标准 | 实测 | 判定 |
|---|---|---|
| 口播 recall ≥95% | 100%（受控探针） | 达标 |
| 禁用词幻觉率 ≤5% | 0% | 达标 |
| 时间戳 p90 ≤±2s | ~+1.5s 有系统偏移 | 勉强达标，需校准 |

**VLM 的音频判断能力够用，不需要用 ASR 硬定位替代它做漏报兜底。** 但 ASR 通道不白做，角色调整为三个互补位：

1. **时间戳校准锚点**：VLM +1.5s 偏移可用 ASR 段边界修正（阶段二的"segment 索引引用"门禁改为此形态：VLM 结论仍有效，时间以 ASR 为准）；
2. **禁用词漏检保险**：VLM 不调用 forbidden 检查工具时（P2/P3 的行为），用 ASR 文本全量扫描兜底证明覆盖，而不是整单作废；
3. **文本证据**：与脚本审核 verified-quote 同构——VLM 的口播命中须引用 ASR segment，程序核验。

**优先修的其实是两个工程缺陷**（不是模型能力）：最终报告 JSON 遵循度（可复用脚本审核的 fence 剥离 + revalidate 思路，或工具循环末轮 reminder），和组件调用完整性（system prompt 已写"所有规则组件须实际调用"但仍漏调，需要轮间硬提醒或把未调用组件在预算耗尽前强制补一轮）。这两个不修，阶段二/三设计得再好端到端吞吐也是 0。

## 样本局限（诚实声明）

合成探针=清晰单说话人 TTS、短句、词表小、无方言/多人/快语速。真实达人成片难度高一档，上述"达标"结论应在 2-3 条真实中文成片（人工听标）上复验后再定稿。BGM 实验只测到 0.3 音量正弦波，未测真实音乐（频段冲突更复杂）。
