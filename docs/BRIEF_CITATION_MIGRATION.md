# 更新 Brief 后的引用迁移

在保存项目规则、冻结新版本时，自动核对引用的旧图文解析。只迁移同项目成功解析中真实存在的引文，且新版同一物理页、相同来源类型（text/visual）只有一个原文块包含完全相同引文。

不跨页搜索，不做模糊匹配，不改写引文或规则判据；旧出处不存在、属于其他项目、旧回复没有该引文、新版内容变化或目标定位不唯一，仍由原有引用校验拦截。相同 Brief 版本内历史解析引用继续沿用现有校验逻辑。

主引用和 sourceReferences 分别迁移，后者同步更新稳定引用 ID。新冻结规则的 source.citationMigration 保存方法 same_page_exact_quote_v1、新版来源 ID 及新旧块映射。历史规则、旧审核和模型原始回复保持原样；不发起模型调用。

迁移发生在正常保存事务中。幂等指纹仍按原始请求计算；保存失败不留半成品，重放已成功请求不再次生成版本。现有规则更新失效机制继续生效。此迁移只证明引文可定位，不证明要求在新版语境下仍然适用，品牌仍需核对新版规则内容。
