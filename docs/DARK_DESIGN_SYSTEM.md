# 暗色审核台设计系统

CSS 变量的完整表见 `frontend/src/styles/tokens.css`；Tailwind / shadcn 语义映射见 `frontend/src/styles/tailwind.css`。这两份文件先于页面实现落地，后续组件只引用变量。字体自托管 Inter、JetBrains Mono 和 Noto Sans SC，中文优先 PingFang SC。

| 页面 | 常态 | Hover / active | Focus-visible | Disabled | 加载 / 空态 / 错误 |
| --- | --- | --- | --- | --- | --- |
| 应用导航 | 240px 实色侧栏、48px 工具栏 | 弱灰背景；选中琥珀色和左竖条 | 2px 琥珀轮廓 | 降为禁用灰、阻止点击 | 文本骨架、无搜索结果说明、可重试错误 |
| 活动管理 | 44px 表格行、32px 筛选器 | 行底略亮、当前选项金色 | 输入与动作均有焦点轮廓 | 禁用灰，无悬浮提升 | 骨架行；无插画空态；原有错误与重试 |
| 审核队列 | 紧凑中性表格、等宽时间 | 行 hover 高亮 | 筛选和复核链接可键盘使用 | 不可执行动作不可点击 | 骨架行；无待办说明；加载失败重试 |
| 视频证据中心 | 三栏，播放器／证据／信息操作 | 时间锚点与证据联动，选中卡琥珀轮廓 | 播放、跳转、筛选、截图均可键盘操作 | 无视频时控制器禁用 | 播放与证据骨架；空态文案；调用错误保留 |
| 规则与 Brief | 每条一行，提示词折叠 | 行 hover；选中范围琥珀色 | 行内输入和弹层完整焦点样式 | 范围外保留配置，禁用动作降灰 | 原有解析骨架、原文空态、错误重试 |
| 达人反馈 | 单栏柔和对比、建议琥珀引用块 | 点击证据查看／跳转 | 操作与引用链接具备焦点轮廓 | 不可提交状态保留原因 | 骨架、无反馈说明、原有错误展示 |
| 设置 | 分组表单、凹陷输入框 | 控件边框提亮 | 统一焦点轮廓 | 保存／调用锁定原有逻辑 | 骨架、无 Key 状态、接口错误展示 |

不新增未经数据支持的置信度、准确率或漏判数字。参考项弱化并折叠，不与客观不符合项同等呈现。减少动态效果时取消过渡；其余仅使用不超过200ms的 opacity / transform。
