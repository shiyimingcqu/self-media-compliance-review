# Brief 表格分区与规则适用范围

新 VLM 解析沿用一次图文识读和事实提取调用，不增加模型配置或额外调用。提示词要求按实际行列、合并单元格保留文案／图片／视频的归属，不按 PDF 内部文字顺序串接。识读不清的分区需明确记录。

每条事实新增可选 `applicability`：

- `materials`：script、video、image、copy、publish、shared、unknown，可多选。
- `stage`：planning、execution、publishing、all、unknown。
- `section`、`sectionQuote`、`region`：分区名、同页可核对的分区引文和原页区域描述。

代码校验分区引文在事实同页的文字或视觉说明中存在。校验不通过只将范围降为 unknown，保留事实原文。引用存在并不证明 VLM 对合并单元格的理解正确，仍须人工对照版面评估识读质量。

新解析的事实未提供范围时标 unknown。生成前仅发送当前材料适用事实；脚本引用目录也去掉明确跨范围或 unknown 的事实片段。成片执行要求不能直接升级为脚本硬门槛；明确的脚本拍摄安排仍可参与脚本检查。图片与视频共同的合并区域不自动扩展为脚本要求。

结构化返回再次按引用核对范围；某条候选混入不适用的依据时整条略过，保留原始候选在 `excludedCandidates`，不猜测改写其中部分内容。基础脚本模板继续由代码保留。生成快照记录 `factScopeVersion=material_stage_v1`、完整事实、`excludedFacts`、完整引用目录和实际发送的 `generationSourceReferences`。段落模式通过输入筛选和提示词限制范围，不宣称有结构化引用级的范围拦截。

历史事实缺字段时保持兼容，不自动猜范围或覆盖已保存规则；历史解析、审核与原始模型回复保持原样。要获得旧 PDF 的新分区理解，需要用户重新发起图文解析及规则生成，不自动重发付费请求。本地重校验新规则生成记录沿用其冻结范围。

测试使用固定响应，覆盖同文不同分区、合并图片／视频区域、未知范围、分区引文无依据、脚本安排与成片执行分离、混合引用拦截、基础模板保留、单次调用及幂等。测试通过证明结构和分发逻辑，不证明真实模型的视觉归属判断准确率。
