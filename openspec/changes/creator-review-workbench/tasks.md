- [ ] 1.3 实现 SQLite 迁移、文件元数据及模式命名空间；验证两个模式数据隔离，版本记录不可覆盖。
- [ ] 1.4 实现 AppShell、路由、状态标签、主题令牌和错误/空态；按 FND-01/05/06 在 1440px 与 1024px 验证导航、刷新和键盘可用性。
- [ ] 1.5 建立公共 API 客户端、错误 envelope、revision 与幂等约定；集成测试验证重复请求与过期编辑不会重复写入。
