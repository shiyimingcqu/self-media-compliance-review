# 模型与运行设置

## Purpose

配置真实模型接入和运行参数，安全管理服务端凭证，明确区分文本连通性与完整音视频能力，在切换演示及真实模式时维持审核结果来源一致，避免依据图稿中的模型名称和示意限制误导用户或放行不可执行的审核任务。

## ADDED Requirements

### Requirement: MS-01 可用适配器与模型配置
系统 SHALL 只允许已实现的服务商适配器用于真实审核，分别配置文本及视频能力，不得将未知文本模型默认认定为视频模型。

#### Scenario: 手动输入未知模型
- **WHEN** 用户配置没有视频验证记录的模型 ID
- **THEN** 可保存待验证配置，但禁止真实视频审核并显示未验证

### Requirement: MS-02 密钥只在服务端保存
系统 MUST 加密存储已保存密钥，前端只接收掩码和存在状态，日志不含密钥，不能回显旧明文。

#### Scenario: 点击查看密钥
- **WHEN** 用户查看已保存配置且没有输入替换值
- **THEN** 不提供旧明文；仅对本次尚未保存的新输入提供显隐切换

#### Scenario: 保存其他字段未改密钥
- **WHEN** 用户仅修改并发数后保存
- **THEN** 保留原密钥，不将掩码作为新密钥发送或保存

### Requirement: MS-03 分项连接与完整视频能力验证
系统 MUST 区分文本连接、完整视频输入和音轨处理测试，显示证据及时间；文本成功不得直接使视频测试成功。

#### Scenario: 文本成功视频失败
- **WHEN** 文本调用成功但视频输入被供应商拒绝
- **THEN** 显示文本可用与视频不可用，真实视频审核仍禁用

### Requirement: MS-04 经过验证的能力与限制
系统 SHALL 显示音频能力、容器、大小、时长、来源及验证时间，未知值显示未验证；模型或地址变化使关联验证失效。

#### Scenario: 更改服务地址
- **WHEN** 用户保存新接口地址
- **THEN** 原能力验证标记失效，不继续展示为当前模型能力

### Requirement: MS-05 演示真实模式切换
系统 MUST 仅在凭证、配置与完整音视频链路有效后启用真实模式，演示模式不向真实模型发送业务文件。

#### Scenario: 缺少视频能力切换真实
- **WHEN** 用户选择真实模式但没有通过完整视频及音轨验证
- **THEN** 保存时拒绝模式生效并列出缺项，可继续保留演示模式

### Requirement: MS-06 运行参数与快照
系统 SHALL 校验超时为 30–1800 秒、并发为 1–10、重试为 0–3 的整数；配置仅对新作业生效，已有作业保留原快照。

#### Scenario: 配置零并发
- **WHEN** 用户输入并发数为零并提交
- **THEN** 显示范围错误，不改变已生效配置

#### Scenario: 审核期间修改模型
- **WHEN** 用户保存新模型配置且旧作业尚在运行
- **THEN** 旧作业保留原模型和模式，后续作业使用新配置

### Requirement: MS-07 接口地址安全与错误可用性
系统 MUST 验证外部服务地址并阻止回环、内网、元数据地址及重定向绕过；连接失败显示脱敏原因及可重试操作。

#### Scenario: 连接测试指向内网
- **WHEN** 用户填写云元数据或本机管理接口地址并测试
- **THEN** 服务端拒绝请求且不访问该地址，显示地址不允许而不泄露系统环境

### Requirement: MS-08 保存取消与草稿模式
系统 SHALL 在保存成功后更新已生效配置和模式横幅，取消恢复已保存值，失败保留输入并显示错误。

#### Scenario: 选择模式但未保存
- **WHEN** 用户在表单选择真实模式后取消
- **THEN** 恢复原选择，其他页面和顶部横幅仍为原已生效模式
